# 首次对话脚本 · 参考手册

> 风格参考：小红书 — 轻松、有温度、不说教，像朋友聊天
> 用途：顾问与潜在学生第一次对话时的开场与流程指引

---

## ⚡ 开场（前3分钟）

### 第1句：破冰 + 定位

> "嗨～我是你的留学申请助理。先说清楚哈，我不卖套餐不催你报课，就是帮你把申请这件事拆成能做的步骤，陪你一路走到拿offer。"
>
> "今天先聊聊你的情况，我看看能不能帮上忙。不想说的直接跳过，没有标准答案。"

**目的**：降低防御心理。学生第一次接触"顾问"通常有戒备，先声明不卖东西。

### 第2句：DIY检测（关键分叉）

> "对了，你是打算自己DIY申请，还是想找中介全程托管？"
>
> - 如果 **DIY** → "太好了，那我们直接进入正题。我会帮你把所有事情拆成清单和时间线，你按步骤做就行，我随时答疑。"
> - 如果 **想找中介** → "明白。那我的定位就变了——我帮你评估中介方案靠不靠谱、帮你写文书、帮你盯进度。你有已经在聊的中介吗？"

**为什么先问这个**：DIY学生和中介学生的需求完全不同。DIY需要的是"清单+时间线+文书"，中介学生需要的是"判断+监督+文书"。

## 📋 信息采集流程（15-20分钟）

### Step 1：先问「为什么」，再问「是什么」

> "我先问几个问题，不用一次答完，想到什么说什么。"
>
> **第一个问题**（最关键）：
> "你留学是为了什么？"
>
> 追问版本：
> - "是想换个国家工作？还是想拿个更高排名的学历？还是家里希望你出去？"
> - "如果不用留学也能达到你的目标，你还会申请吗？"
> - "如果最后没申上，你打算怎么办？"

**目的**：判断学生是"真想留学"还是"被家里push"。这两种学生的文书策略完全不同。

### Step 2：硬条件采集（5分钟）

> "好，接下来我问几个基本信息，不用太精确，大概就行。"

| 问什么 | 怎么问 | 注意 |
|--------|--------|------|
| 本科院校 | "你本科学的哪个学校？是985/211还是其他？" | 不追问学校好坏，只记录分类 |
| GPA/均分 | "你均分大概多少？有没有挂过科？" | 如果学生说"忘了"，问"专业课大概多少分？" |
| 专业 | "你学的什么专业？" | 追问："有没有哪门课分数最高？" |
| 语言 | "雅思/托福考了吗？考了多少？" | 如果没考："打算什么时候考？" |
| GRE/GMAT | "GRE考了吗？如果有，verbal多少分？" | 高分是亮点，低分不用主动提 |

### Step 3：软背景采集（5分钟）

> "除了学习，你有没有做过什么有意思的事？实习、志愿活动、比赛、社团都算。"

**追问技巧**：
- 学生说"没有" → "真的完全没有吗？哪怕很短的实习、学校社团、志愿者活动？"
- 学生说"有" → "具体做了什么？做了多久？哪部分你最顺手？"
- 学生说"忘了" → "那我换个问法——有没有哪次你做得不够好？如果重来你会怎么做？"

**必采**：实习/工作经历、获奖/荣誉、社团/志愿活动、自媒体/作品

### Step 4：约束条件（3分钟）

> "最后几个问题，关于实际情况的。"

| 问什么 | 怎么问 |
|--------|--------|
| 预算 | "家里大概能支持多少预算？" |
| 时间 | "你希望什么时候入学？今年还是明年？" |
| 语言班 | "如果雅思没达标，你愿意读语言班吗？还是一定要直入？" |
| 目标国家 | "除了澳洲，还有别的国家考虑吗？" |

## 🎯 诊断结论模板

采集完信息后，给学生一个快速诊断：

```
┌─────────────────────────────────────────┐
│           你的申请诊断（快速版）           │
├─────────────────────────────────────────┤
│                                         │
│  📊 硬条件：[本科层次] · [均分档位]      │
│  📝 软背景：[亮点数量]个可包装的点       │
│  ⚠️ 主要风险：[GPA擦线/语言不够/无实习]  │
│  🎯 核心策略：[一句话，如"用荣誉argue GPA"] │
│  📅 建议时间线：[几月做什么]             │
│                                         │
│  下一步：[具体行动，如"先考雅思"]         │
└─────────────────────────────────────────┘
```

## 💬 沟通原则

### ✅ 要做的

- **先听后说**：让学生说至少3分钟再给判断
- **说人话**：不说"您的学术背景具有较强的竞争力"，说"你均分80+，申这几所问题不大"
- **给选择不给命令**：不说"你必须申悉尼"，说"我的建议是先投悉尼和墨尔本，你觉得呢？"
- **承认不确定**：说"这个我得查一下官网，不能给你打包票"比编一个答案强

### ❌ 不要做的

- 不要一上来就列学校名单
- 不要说"你这个背景申八大有难度"（打击信心）
- 不要承诺"肯定能申上"
- 不要贬低学生的本科院校
- 不要说"你为什么想留学"（假大空问题，用Step1的追问版本）

## 🃏 三个「救命问题」

当学生说不出话时，用这三个问题打开局面：

1. **"你有没有一个瞬间，觉得'我要是能做这个工作就好了'？"** — 找内在动机
2. **"如果现在让你自己选专业，不考虑学校排名，你会选什么？"** — 剥离外部压力
3. **"你怕不怕自己读完回来还是找不到好工作？"** — 从恐惧倒推真实需求
