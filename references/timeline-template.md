# 申请时间线 · 模板与甘特图

> 用途：定校方案确定后，生成个性化时间线，包含甘特图 + 可喂给AI的定时提醒prompt

---

## 1. 时间线生成规则

根据以下变量，自动生成时间线：

| 变量 | 来源 | 影响 |
|------|------|------|
| 目标入学时间 | 学生选择 | 7月入学 vs 次年2月入学 |
| 当前日期 | 系统时间 | 所有节点倒推 |
| 语言成绩状态 | 学生提供 | 已达标/未达标/未考 |
| 目标国家 | 定校方案 | 澳洲（滚动录取多）vs 英国（固定截止多） |
| 学生类型 | DIY/中介 | DIY需要更详细的步骤分解 |

## 4. AI定时提醒 Prompt（直接复制使用）

> 定校方案确认后，把下面这段prompt喂给你的AI助手（ChatGPT/Claude/WorkBuddy都行），它会帮你盯进度。

```
你是我留学申请的AI助理。请根据以下信息，帮我制定并持续追踪申请进度。

## 我的基本信息
- 目标入学时间：[202X年X月]
- 目标国家：[澳洲/英国/...]
- 语言状态：[已达标/未考/需要刷分]
- DIY还是中介：[DIY/有中介]

## 我的定校方案
- 冲刺校：[学校1]、[学校2]、[学校3]
- 主申校：[学校4]、[学校5]、[学校6]
- 保底校：[学校7]、[学校8]

## 已知截止日期
- [学校1]：[日期]（滚动录取/固定截止）
- [学校2]：[日期]
- ...（以此类推，把所有学校的截止日期列出来）

## 请帮我做以下事情

### 1. 生成甘特图
用ASCII甘特图展示从今天到入学的完整时间线，标注每个关键节点。

### 2. 每周提醒
每周提醒我以下事项（按优先级排序）：
- 如果有考试还没考 → 提醒报名/备考
- 如果PS还没写 → 提醒进度
- 如果推荐信还没提交 → 提醒联系推荐人
- 如果投递窗口即将关闭 → 紧急提醒
- 如果等待超过2周 → 提醒跟进学校

### 3. 截止日期倒计时
对每个学校的截止日期，提前2周、1周、3天分别提醒一次。

### 4. 材料检查
每周检查一次：所有材料是否齐备？缺什么？

### 5. 风险预警
如果发现以下情况，立即提醒我：
- 语言成绩一直没出分
- 推荐人不回复
- 某所学校截止日期过了还没投
- 收到拒信后需要调整策略

请在每次对话开始时，主动问我本周的进度情况，并给出下一步建议。
```

## 5. DIY学生的特别时间线

DIY学生没有中介帮忙盯进度，时间线需要更详细：

| 额外步骤 | 说明 |
|---------|------|
| 官网注册账号 | 每所学校单独注册，记住密码 |
| 材料扫描归档 | 建一个文件夹，所有材料按学校分类 |
| 申请系统填写 | 留出额外时间，每所学校约1-2小时 |
| 送分操作 | 雅思/PTE官方送分，提前2-4周操作 |
| 跟进邮件模板 | 准备好跟进邮件，到时间就发 |
| Offer对比表 | 收到多个Offer后，用表格对比 |

### DIY额外prompt（在第4节prompt基础上追加）

```
## DIY特别提醒
- 每所学校需要单独注册申请账号，请提前注册
- 申请系统填写容易出错，每所学校留2小时
- 雅思/PTE送分需要提前操作，不要卡在截止日
- 准备好跟进邮件模板，收到结果后主动跟进
```
