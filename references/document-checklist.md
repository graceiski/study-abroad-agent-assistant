## 🎓 学历证明类（详细说明）

### 1. 毕业证 + 学位证

- **已毕业**：提供原件扫描件 + 翻译件（英文）
- **未毕业**：提供在读证明（中英文），毕业后补交
- **翻译**：自己翻译即可，无需公证（除非学校特殊要求）
- **格式**：PDF扫描件，彩色，清晰

### 2. 成绩单

- **内容**：所有学期、所有课程、分数、学分
- **格式**：中英文各一份，加盖学校公章
- **注意**：
  - 如果成绩单上没有均分，需要单独开均分证明
  - 如果有挂科记录，不需要隐瞒（澳洲学校会看到）
  - 部分学校要求成绩单通过学信网认证

### 3. 均分证明

- 中英文各一份，加盖公章
- 内容：总均分、专业课均分、排名（如有）
- 部分学校（如墨尔本大学）有特定的均分计算方式，需提前确认

## 👤 个人信息类

### 4. 个人简历（CV）

- **长度**：1-2页A4
- **结构**：
  - 个人信息（姓名、邮箱、电话）
  - 教育背景（学校、专业、学位、时间、GPA/排名）
  - 实习/工作经历（公司、职位、时间、3-5个bullet points）
  - 项目/研究经历（课程项目、毕业论文、比赛）
  - 技能（语言、软件、证书）
  - 荣誉/活动（获奖、社团、志愿活动）
- **格式**：英文，简洁，无照片无花哨设计

### 5. 推荐信

- **数量**：2封（学术推荐人优先）
- **推荐人选择**：
  - 优先：给你高分的专业课老师
  - 其次：实习/工作主管
  - 避免：家人、朋友、没有交集的名人
- **内容**：推荐人说明与你的关系、对你能力的评价、具体事例
- **提交方式**：推荐人直接发邮件给学校，或上传到申请系统
- **提前准备**：给推荐人发一封邮件，附上你的简历+PS+申请学校清单

### 6. 申请文书（PS/SOP）

- **每所学校独立版本**（模块化写作，见 modular-document-approach.md）
- **长度**：800-1000词（通用Body）+ 100-150词（Why School段）
- **注意**：不要用同一篇PS申所有学校——Why School段必须每校独立写

### 7. 动机信（Cover Letter）

- 部分学校需要（如墨尔本大学部分专业）
- 比PS更短（300-500词），更聚焦
- 内容：为什么申这个专业 + 为什么选这个学校 + 职业目标

## 🌐 语言类

### 8. 雅思/托福

- **考试**：雅思（IELTS Academic）或托福（TOEFL iBT）
- **送分**：通过官方机构送分到学校（需要时间，提前2-4周操作）
- **有效期**：考试日期到入学日期需在2年内
- **分数要求**：澳洲硕士通常雅思6.5（6.0），八大通常7.0（6.0-6.5）

### 9. PTE Academic

- **澳洲广泛接受**，出分快（通常1-5个工作日）
- **分数对照**：PTE 58≈雅思6.5，PTE 64≈雅思7.0
- **送分**：通过Pearson官网送分

### 10. Duolingo English Test

- 部分澳洲学校接受（如RMIT、QUT、部分私立学院）
- 但八大中多数仍以雅思/PTE为主
- **注意**：接受度不如雅思/PTE，定校时需确认

## 💼 加分项

### 11. GRE/GMAT

- 澳洲硕士多数不要求GRE
- 商科部分项目要求GMAT（如墨尔本大学商学院）
- 如果有GRE高分（Verbal高百分位），主动提交作为补充材料

### 12. 实习/工作证明

- 中英文各一份，盖公司公章
- 内容：职位、时间、职责简述
- 如果公司不给盖章，可以用工作证+在职邮件截图代替（部分学校接受）

### 13. 作品集

- 传媒/设计/建筑类专业必须
- 格式：PDF，10-20页
- 内容：作品截图+简短说明（你做了什么、用了什么工具、为什么这样设计）

---

## 📋 签证类（录取后准备）

### 14. 银行存款证明

- 中英文，银行开具
- 金额：覆盖第一年学费+生活费（澳洲通常需要30-40万人民币）
- 有效期：通常3个月，注意时间衔接

### 15. 户口本

- 复印件
- 翻译件（部分签证要求）

## ⏱️ 材料准备时间线

| 时间 | 事项 |
|------|------|
| 申请前6个月 | 考雅思/PTE（预留刷分时间） |
| 申请前4个月 | 开成绩单/在读证明/均分证明（学校假期办理需提前） |
| 申请前3个月 | 联系推荐人、写PS初稿 |
| 申请前2个月 | 完成各校PS、联系推荐人提交 |
| 申请前1个月 | 雅思送分、材料扫描归档 |
| 申请提交后 | 等待结果、补交材料 |
| 录取后 | 办签证材料（存款证明、体检、保险） |

## 📎 实用技巧

1. **所有材料扫描存云盘**，命名格式：`姓名_材料名_日期.pdf`
2. **成绩单和在读证明提前开好**——学校假期不办公，临时开会耽误事
3. **推荐信提前2个月联系**——老师很忙，不要临时抱佛脚
4. **雅思送分提前操作**——官方送分需要时间，不要卡在截止日
5. **PS不要用同一版**——Why School段必须每校独立写，招生官之间会交流
6. **材料备份**：所有文件留一份在本地+一份在云端
